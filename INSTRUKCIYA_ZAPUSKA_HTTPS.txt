Запуск проекта после доработки HTTPS

1. Backend:
   cd backend
   npm install
   npm run dev

   Сервер запустится по адресу:
   https://localhost:5000

2. Frontend:
   cd frontend
   npm install
   npm run dev

   Клиент запустится по адресу:
   https://localhost:5173

Важно:
При первом открытии браузер может показать предупреждение о локальном сертификате.
Для дипломного локального проекта это нормально: используется самоподписанный сертификат localhost.
Нужно открыть https://localhost:5000 и https://localhost:5173 и разрешить переход.

Что добавлено:
- HTTPS для backend;
- HTTPS для frontend;
- ограничение неверных попыток входа;
- полноценная регистрация жильца;
- автоматическое создание профиля жильца при регистрации;
- пояснение на форме входа о защите от перебора паролей.

Если HTTPS мешает запуску:
1. backend/.env: поставить USE_HTTPS=false
2. frontend/.env: поставить VITE_USE_HTTPS=false и VITE_API_URL=http://localhost:5000/api
