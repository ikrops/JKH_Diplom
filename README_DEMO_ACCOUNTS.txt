Демонстрационная база ЖКХ

После запуска:
cd backend
npm run seed

Будут созданы данные для 20-этажного дома:
- 1 этаж нежилой;
- жилые этажи: со 2 по 20;
- 6 квартир на каждом жилом этаже;
- всего 114 квартир;
- у каждой квартиры есть основной жилец-владелец;
- у каждого владельца есть аккаунт для входа в личный кабинет;
- количество проживающих в квартире задаётся от 1 до 5;
- добавлены услуги, тарифы, показания, начисления, оплаты и должники.

Основные аккаунты:
Администратор: admin / admin123
Сотрудник: employee / employee123
Бухгалтер: accountant / accountant123

Аккаунты жильцов:
resident001 / resident123
resident002 / resident123
...
resident114 / resident123

Примеры для проверки личного кабинета:
resident001 / resident123
resident025 / resident123
resident114 / resident123
