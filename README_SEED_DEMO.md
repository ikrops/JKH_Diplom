# Демонстрационное заполнение базы данных

В проект добавлен расширенный seed-скрипт `backend/src/seed.js`.

Он создаёт демонстрационный дом:

- 20 этажей;
- 1 этаж нежилой: ресепшен/служебные помещения;
- со 2 по 20 этаж — жилые этажи;
- 6 квартир на каждом жилом этаже: 3 слева и 3 справа;
- всего 114 квартир.

Также создаются:

- пользователи разных ролей;
- жильцы;
- коммунальные услуги;
- история тарифов;
- показания счётчиков;
- начисления;
- частичные и полные оплаты;
- задолженности;
- запись в журнале действий.

## Как заполнить базу

1. Перейти в backend:

```bash
cd backend
```

2. Установить зависимости, если ещё не установлены:

```bash
npm install
```

3. Запустить заполнение базы:

```bash
npm run seed
```

## Тестовые пользователи

Администратор:

```text
admin / admin123
```

Сотрудник:

```text
employee / employee123
```

Бухгалтер:

```text
accountant / accountant123
```

Жилец:

```text
resident001 / resident123
```

Также созданы жильцы `resident002`, `resident003`, `resident004`, `resident005`, `resident006` с тем же паролем `resident123`.
